## Codespaces
[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Funtasia/app-funtasia?quickstart=1)

It can be useful to use GitHub codespaces as it is a Linux environement which has been tested. Other than that, it is basically a VS Code instance running on their servers, thus there is a usage limit per month, but work on the same codespace is preserved across multiple devices.

## Recomended VSCode extentions
1. Tailwind CSS IntelliSense (bradlc.vscode-tailwindcss) for completion in .css files and in html classes. [[Open-VSX]](https://open-vsx.org/extension/bradlc/vscode-tailwindcss) [[Visual Studio Marketplace]](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)
2. [Optional] Catppuccin for VSCode (catppuccin.catppuccin-vsc) to get used to the Catppuccin color scheme [[Open-VSX]](https://open-vsx.org/extension/Catppuccin/catppuccin-vsc) [[Visual Studio Marketplace]](https://marketplace.visualstudio.com/items?itemName=Catppuccin.catppuccin-vsc)

## Recommended reading
* [The Git book on submodules](https://git-scm.com/book/en/v2/Git-Tools-Submodules) (Feel free to check out the other chapters about Git to better understand how it works.)
* [Optional] [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel) as an option to expose the dev server to the public via a https tunnel. Another option would be to use a Microsoft Dev Tunnel (found in the PORTS section of VS Code and in Github Codespaces).
